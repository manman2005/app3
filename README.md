# ระบบจัดตารางสอนอัตโนมัติ

Web Application สำหรับระบบจัดตารางสอนอัตโนมัติ พัฒนาด้วย PHP (PDO), Tailwind CSS และ MySQL

## ฟีเจอร์หลัก

✅ **ระบบล็อกอิน / ออกจากระบบ (Admin Authentication)**
- ระบบ Authentication สำหรับผู้ดูแลระบบ
- Session Management

✅ **ระบบจัดตารางสอนอัตโนมัติ (Automatic Timetable Generation)**
- ใช้อัลกอริทึมตรวจสอบเวลาว่างของครู ห้องเรียน และวิชา
- ป้องกันการชนกันของตารางสอน
- ตรวจสอบความพร้อมของครูและห้องเรียน

✅ **ระบบจัดการข้อมูลพื้นฐาน (Master Data Management)**
- นักเรียน (Students) - CRUD
- ครู (Teachers) - CRUD
- วิชา (Subjects) - CRUD
- ห้องเรียน (Classrooms) - CRUD

✅ **ระบบแสดงตารางสอน**
- แสดงตารางตาม "วัน" และ "คาบเรียน"
- สามารถดูตารางของครู นักเรียน หรือห้องเรียนได้
- แสดงในรูปแบบตารางที่อ่านง่าย
- ส่งออกตารางสอนเป็นไฟล์ PDF ได้

✅ **ระบบหลังบ้าน (Admin Dashboard)**
- สรุปจำนวนครู, นักเรียน, วิชา, ห้องเรียน
- แสดงภาพรวมของตารางสอนล่าสุด

✅ **Responsive Design**
- ใช้ Tailwind CSS
- รองรับการแสดงผลบนมือถือและแท็บเล็ต

## ความต้องการของระบบ

- PHP 7.4 หรือสูงกว่า
- MySQL 5.7 หรือสูงกว่า
- Apache Web Server (XAMPP, WAMP, หรือ LAMP)
- PDO Extension สำหรับ PHP
- Composer (สำหรับติดตั้ง Dompdf)

## การติดตั้ง

### 1. ติดตั้งฐานข้อมูล

1. เปิด phpMyAdmin หรือ MySQL Command Line
2. นำเข้าไฟล์ `database/schema.sql` เพื่อสร้างฐานข้อมูลและตาราง
   ```sql
   source database/schema.sql
   ```
   หรือคัดลอกเนื้อหาในไฟล์ `database/schema.sql` แล้วรันใน phpMyAdmin

### 2. โหลดข้อมูลจำลอง (ทางเลือก)

นำเข้าไฟล์ `database/sample_data.sql` เพื่อเพิ่มข้อมูลตัวอย่าง 10 แถวในแต่ละตาราง:

```sql
source database/sample_data.sql
```

หรือรันผ่าน phpMyAdmin โดยคัดลอกเนื้อหาไปวางแล้วรันคำสั่ง

### 3. ตั้งค่า Database Connection

แก้ไขไฟล์ `config/database.php` ตามการตั้งค่าของคุณ:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'timetable_db');
```

### 4. ติดตั้งไลบรารี Dompdf

ใช้ Composer เพื่อติดตั้งไลบรารีสำหรับส่งออก PDF (รันในโฟลเดอร์โปรเจกต์):

```bash
composer require dompdf/dompdf
```

### 5. ตั้งค่า Web Server

- วางโปรเจกต์ในโฟลเดอร์ `htdocs` (XAMPP) หรือ `www` (WAMP)
- เปิดเว็บเบราว์เซอร์และไปที่: `http://localhost/app3`

### 6. ตั้งค่าผู้ใช้ Admin

รันสคริปต์ `setup_admin.php` เพื่อสร้างหรืออัปเดตผู้ใช้ admin:
- เปิดในเบราว์เซอร์: `http://localhost/app3/setup_admin.php`
- หรือรันผ่าน command line: `php setup_admin.php`

**หมายเหตุ:** หลังจากใช้งานแล้ว กรุณาลบไฟล์ `setup_admin.php` เพื่อความปลอดภัย

### 7. เข้าสู่ระบบ

**ข้อมูลเริ่มต้น:**
- ชื่อผู้ใช้: `admin`
- รหัสผ่าน: `admin123`

## การใช้งาน

### 1. จัดการข้อมูลพื้นฐาน

1. **เพิ่มครู**: ไปที่หน้า "ครู" และเพิ่มข้อมูลครู
2. **เพิ่มวิชา**: ไปที่หน้า "วิชา" และเพิ่มวิชาที่ต้องการ
3. **เพิ่มห้องเรียน**: ไปที่หน้า "ห้องเรียน" และเพิ่มห้องเรียน
4. **เพิ่มนักเรียน** (optional): ไปที่หน้า "นักเรียน" และเพิ่มข้อมูลนักเรียน

### 2. สร้างตารางสอนอัตโนมัติ

1. ไปที่หน้า "สร้างตารางอัตโนมัติ"
2. คลิกปุ่ม "สร้างตารางสอนอัตโนมัติ"
3. ระบบจะสร้างตารางสอนโดยอัตโนมัติโดยตรวจสอบ:
   - เวลาว่างของครู
   - ความพร้อมของห้องเรียน
   - ป้องกันการชนกันของตารางสอน

### 3. ดูตารางสอน

1. ไปที่หน้า "ตารางสอน"
2. เลือกตัวกรอง:
   - **ทั้งหมด**: แสดงตารางสอนทั้งหมด
   - **ครู**: เลือกครูเพื่อดูตารางสอนของครูคนนั้น
   - **นักเรียน**: เลือกนักเรียนเพื่อดูตารางเรียนรายบุคคล
   - **ห้องเรียน**: เลือกห้องเรียนเพื่อดูตารางการใช้ห้อง
3. คลิกปุ่ม **ดาวน์โหลด PDF** เพื่อส่งออกตารางสอนตามตัวกรองที่เลือก

## อัลกอริทึมการจัดตารางสอน

ระบบใช้ Greedy Algorithm ในการจัดตารางสอน:

1. **ตรวจสอบเวลาว่างของครู**: ครูไม่สามารถสอน 2 วิชาในเวลาเดียวกัน
2. **ตรวจสอบความพร้อมของห้องเรียน**: ห้องเรียนไม่สามารถใช้ซ้ำในเวลาเดียวกัน
3. **จัดสรรอัตโนมัติ**: ระบบจะพยายามจัดสรรตารางสอนให้ครบทุกวิชา
4. **ป้องกันการชนกัน**: มีการตรวจสอบและป้องกันการชนกันของตารางสอน

## หมายเหตุ

- ตารางสอนจะถูกสร้างสำหรับ 5 วัน (จันทร์-ศุกร์)
- แต่ละวันมี 8 คาบเรียน
- เมื่อสร้างตารางสอนใหม่ ตารางสอนเดิมจะถูกลบทั้งหมด

## การแก้ไขปัญหา

### ปัญหา: ไม่สามารถเชื่อมต่อฐานข้อมูลได้

- ตรวจสอบการตั้งค่าใน `config/database.php`
- ตรวจสอบว่า MySQL Server ทำงานอยู่
- ตรวจสอบว่าฐานข้อมูล `timetable_db` ถูกสร้างแล้ว

### ปัญหา: Session ไม่ทำงาน

- ตรวจสอบว่า PHP Session extension เปิดใช้งาน
- ตรวจสอบสิทธิ์การเขียนไฟล์ในโฟลเดอร์ temp

### ปัญหา: หน้าเว็บไม่แสดงผล

- ตรวจสอบว่า Apache Server ทำงานอยู่
- ตรวจสอบ path ของโปรเจกต์
- ตรวจสอบ error log ของ Apache
